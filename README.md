# Лабораторная работа № 7 — SPA «Планировщик»

**Вариант:** 14 (средний уровень)  
**Технологии:** HTML5, CSS3, JavaScript без фреймворков.

## Возможности
- Вкладки «Сегодня», «Неделя», «Архив».
- Добавление записей с названием, датой и категорией.
- Перенос записи в архив и восстановление.
- Удаление записей.
- Сохранение данных в `localStorage`.
- Счётчики записей на вкладках и адаптивный интерфейс.

## Запуск
Откройте `index.html` в браузере. Для этой версии сервер не требуется.

## Проверки
1. Стартовая вкладка «Сегодня» отображается при открытии.
2. Добавление корректной записи отображает её в соответствующем разделе.
3. Пустое название не проходит встроенную проверку формы.
4. Кнопка «В архив» перемещает запись в архив.
5. Кнопка «Вернуть» возвращает запись в активные.
6. После перезагрузки сохранённые записи остаются в браузере.
7. Удаление убирает запись и обновляет счётчики.

## Вывод
Создан SPA-планировщик с динамическим управлением задачами, фильтрацией по разделам и сохранением состояния в `localStorage`.
