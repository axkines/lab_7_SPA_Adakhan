# Лабораторная работа № 7 — SPA «Управление мероприятиями»

**Вариант:** 20 (повышенный уровень)  
**Технологии:** HTML5, CSS3, JavaScript без фреймворков.

## Возможности
- Вкладки «События», «Регистрация», «Участники».
- Создание событий с датой, временем, местом и вместимостью.
- Регистрация участников с проверкой email, повторной регистрации и свободных мест.
- Динамический список участников и поиск.
- Удаление регистрации.
- Сохранение данных в `localStorage`.
- Адаптивная вёрстка и сообщения об ошибках.

## Запуск
Откройте `index.html` в браузере. Сервер не нужен.

## Проверки
1. При открытии отображаются три демонстрационных события.
2. Создание события с заполненными полями добавляет карточку.
3. Пустые обязательные поля не позволяют отправить форму.
4. Участник регистрируется на выбранное событие.
5. Повторная регистрация того же email на одно событие блокируется.
6. При заполнении вместимости новые регистрации не принимаются.
7. Поиск фильтрует список участников.
8. Данные сохраняются после перезагрузки страницы.

## Вывод
Создано SPA для управления мероприятиями. Реализованы формы, валидация пользовательского ввода, динамические списки, поиск и локальное сохранение данных.
